生产闭环

从当天运行到下一版模型
1. 监控运行按区域和本地时区触发削峰检测、场景识别和功率还原。
2. 自动归因汇总功率插值失败、重复索引、无功率、气象缺失和接口契约问题。
3. 样本回流把失败原因沉淀成高价值样本池，重构数据集和场景标签。
4. 灰度进化新旧模型复用同一份输入并行推理，依据收益和稳定性晋升。

失败最多的原因是什么？
失败最多的是功率数据插值失败，其次是重复索引和无功率数据。Agent 会把这些问题分桶进入数据质量集、预处理规则集和可用性报表，而不是直接污染训练样本。
日终建议：
1. 优先处理 Europe/Berlin 和 Europe/London 的失败链路。
2. 对重复 timestamp 训练前统一聚合或去重。
3. 将无功率数据标记为可用性问题，不作为负样本训练。
4. 候选模型进入灰度前，需要通过收益、稳定性和接口契约三类指标。
